# Livros & Sementes

O **Livros & Sementes** é uma plataforma web colaborativa desenvolvida com o objetivo de incentivar o compartilhamento gratuito de livros usados e sementes para plantio.

A proposta do projeto é aproximar pessoas por meio da leitura, da sustentabilidade e do compartilhamento, permitindo que itens que muitas vezes ficam sem utilização possam encontrar novos leitores, novos espaços para cultivo e novas oportunidades dentro da comunidade.

> **Conhecimento que circula. Vida que floresce.**

---

## Sobre o projeto

O Livros & Sementes busca criar uma comunidade em que os participantes possam disponibilizar e encontrar livros e sementes para compartilhamento.

A plataforma foi pensada para unir tecnologia, sustentabilidade e incentivo à leitura em um ambiente simples, acessível e responsivo.

Entre os principais objetivos do projeto estão:

- Incentivar a circulação e reutilização de livros;
- Estimular o compartilhamento de sementes;
- Promover práticas sustentáveis;
- Incentivar a leitura e a educação ambiental;
- Aproximar pessoas da comunidade;
- Facilitar o acesso a pontos de troca.

---

## Funcionalidades

Atualmente, o projeto possui:

- Página inicial;
- Página institucional "Sobre";
- Catálogo de livros disponíveis;
- Cadastro de livros para compartilhamento;
- Área de sementes;
- Área de pontos de troca;
- Página de login;
- Página de cadastro de usuário;
- Menu de navegação expansível e responsivo;
- Alternância entre modo claro e modo escuro;
- Layout adaptado para computadores, tablets e dispositivos móveis.

> Algumas funcionalidades ainda estão em desenvolvimento. Os formulários de login e cadastro possuem atualmente a interface preparada, mas ainda não estão conectados a um sistema de autenticação ou banco de dados.

## Como executar o projeto

Para executar o projeto localmente, siga os passos abaixo.

### 1. Clone o repositório

```bash
git clone https://github.com/bsimaslarissaa/livros-e-sementes.git
```

### 2. Acesse a pasta do projeto

```bash
cd livros-e-sementes
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Abra no navegador

O Vite exibirá no terminal o endereço local da aplicação, normalmente:

```text
http://localhost:5173
```
